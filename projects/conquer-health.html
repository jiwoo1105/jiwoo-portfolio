배경과 역할

문서를 찾는 것에서, 답변의 근거로 쓰이게 하는 것까지.

제공된 L2-preview의 가중치를 바꾸지 않고 의료 질의응답을 개선하는 과제였습니다. 문서를 조회해도 필요한 본문이 생성 입력에 전달되지 않거나, 질문의 요구가 답변에서 누락되면 도구 호출의 성공만으로는 충분하지 않았습니다.

저는 초기 MCP 검색·생성 연결과 약물 안전 게이트를 구현하고, 검색 본문이 모델 입력에 포함되는지와 답변이 질문의 요구·근거를 반영하는지를 나누어 검수했습니다. 이후 출력 예산 실험과 멀티턴 응답 지시 보강에도 참여했습니다. 팀의 최종 제출안과 개인 구현 범위는 커밋 단위로 구분했습니다.

기준선과 판단

단계를 더하기 전에, 직접 생성의 성능부터 확인했습니다.

팀 실험 장부에서 검색·라우팅 후보는 29.13점, 순수 L2 직접 생성은 32.44점을 기록했습니다. 팀은 직접 생성을 기준으로 삼고 temperature=0, 답변 요구사항을 다루도록 하는 짧은 지시, thinking 응답이 잘리거나 비면 thinking을 끄고 다시 생성하는 복구를 차례로 검토했습니다.

thinking과 실패 복구를 결합한 동일 동작의 반복 평가에서는 49.72·50.03·47.79점이 나왔습니다. 한편 전체 개발 이력에는 모델 서버 상태와 누적 변경이 함께 달라진 구간도 있어, 서로 다른 후보의 점수 차이를 각 기법의 순수 효과로 계산하지 않았습니다.

개인 실험

출력 예산을 늘렸지만, 점수 개선이라고 단정하지 않았습니다.

출력 상한을 다시 확인하고, 제 후보 e6de327에서 서버 상한 설정을 2,048에서 32,768로 정정하면서 요청 출력 예산은 2,048에서 4,096토큰으로 늘렸습니다. 추론 중 잘림으로 재생성 경로에 들어가는 일을 줄이려는 실험이었습니다. 서버 상한과 실제 요청 예산은 서로 다른 설정입니다.

장부상 이 후보는 49.59점으로, 기준선 반복 3회의 평균 49.18점과 0.41점 차이였습니다. 관측된 반복 변동 안에 있어 토큰 상향만의 개선 근거로 삼지 않았습니다. 점수와 함께 잘림, 폴백 발생, 지연을 확인할 필요가 있었습니다.

최종 접근

직접 생성을 유지하고, 정확한 조회가 필요한 질문에만 MCP를 연결했습니다.

팀의 후속 제출 계열은 검증된 기준선 복원 → 선택적 MCP → 후속 질문의 참조 처리 → 긴 답변 보존으로 발전했습니다. 한국어 약가·허가·성분·질병 코드처럼 명확한 조회에 도구를 제한하고, “그 약·그 코드”의 대상이 최근 대화에서 하나로 정해질 때만 조회하도록 했습니다.

조회가 실패하거나 대상이 모호하면 직접 생성 경로를 유지했습니다. 정상 답변의 뒷부분이 후처리에서 잘리지 않도록 길이 상한도 6,000자에서 12,000자로 늘렸습니다. 이 최종 계열은 팀 공동 산출물이며, 선택적 MCP가 평가 문항에서 실행된 빈도와 점수 기여도는 별도 로그가 있어야 판단할 수 있습니다.

결과와 증빙

벤치마크 1위. 평가 단계별 숫자는 구분해서 남겼습니다.

AIM 팀은 HealthBench 기반 평가 최고점으로 루닛 Conquer Health 벤치마크상을 받았습니다. 팀의 공개 최종 평가 기록은 3라운드 평균 46.51점, 최종 평가 참여 14개 팀 중 1위입니다. 아래 상장은 수상 증빙이며 숫자 점수는 기재하지 않습니다.

이번에 대조한 개발 실험 장부에는 ef3609d의 54.37점과 마감 대시보드 53.53점·1위가 기록돼 있습니다. 이는 최종 3라운드 평가와 다른 기록입니다. 마감 점수를 Trial 56에 대응시키는 연결은 아직 추정이므로 확정된 제출 결과로 표시하지 않았습니다.

배운 점

좋은 실험은, 좋아 보이는 점수를 의심하는 데서 시작했습니다.

같은 동작의 평가가 47.79–50.03으로 2.24점 흔들렸습니다. 팀은 이를 바탕으로 작은 점수 차이를 단일 제출만으로 채택하지 않는 ±2.5점의 경험적 판단 기준을 뒀습니다. 이는 3회 관측에 따른 운영 기준이며 통계적으로 확정된 신뢰구간은 아닙니다.

도구 호출 성공, 답변의 근거 반영, 응답 완결성, 벤치마크 점수는 각각 다른 확인 대상이었습니다. 이 경험 이후에는 기능을 추가했다는 사실보다 어떤 조건에서 무엇이 달라졌는지를 설명하고, 개선을 확인하지 못한 실험도 다음 판단의 근거로 남기려 합니다.

대회 실험·수상 기록입니다. 실제 환자 대상 임상 성능을 검증한 결과는 아닙니다.
