문제

움직임을 복원하는 것에서, 학습 데이터를 만드는 것으로.

여러 사람이 등장하는 영상에서 행동과 3D 모션을 연결하려면 시간 구간과 인물 ID가 함께 맞아야 합니다. 복원이 시각적으로 그럴듯해도 중간에 대상 인물이 바뀌거나 동작 설명이 다른 구간을 가리키면 일관된 데이터로 쓰기 어렵습니다.

모델별 GPU 실행 환경과 실행기, 출력 파서를 정리하고, 원본 영상과 인물 크롭의 메쉬 복원 결과를 비교했습니다. 영상·시간 구간·인물 ID·모션을 함께 검수할 수 있도록 결과를 정리하는 데 집중했습니다.

비교 실험

FPS를 높이는 것만으로 짧은 동작을 찾을 수는 없었습니다.

그라운딩 실험에서 7개 모델, 5개 FPS, 2개 영상, 3개 쿼리로 얻은 210개 응답을 비교했습니다. 입력 샘플링을 촘촘하게 해도 구간을 지나치게 넓게 반환하거나 영상에 없는 동작을 찾는 사례가 남았습니다.

Qwen3-VL의 짧은 구간 행동 판별을 TimeLens2 앞에 연결하는 방식도 살폈습니다. 없는 슛을 걸러낸 사례와 실제 드리블을 놓친 사례가 함께 있어, 오탐과 누락을 원본 장면에서 따로 검수했습니다.

실제 복원

메쉬의 모양과 사람의 일관성을 따로 확인합니다.

이 페이지의 공개 농구 클립은 8초, 100프레임을 CoMotion에 입력한 실제 추론 결과입니다. 출력된 자세·체형·위치 파라미터를 SMPL 인체 메쉬로 변환하고 원본과 같은 시점으로 렌더링했습니다.

CoMotion, Multi-HMR 2와 추적 기반 접근을 비교하며 중복 검출, 가려짐, 인물 ID 변화와 메쉬 품질을 구분해 확인했습니다. 상자 겹침으로 중복을 줄이는 처리만으로 동일 인물의 ID가 유지되는 것은 아니었습니다.

메쉬는 사전학습 모델의 추론 결과입니다. 자체 모델 학습 성과나 로봇 제어·동작 전이 결과를 뜻하지 않습니다. 입력 영상의 권리는 원저작자에게 있습니다.

현재 연구 방향

선수 중심 클립에 설명과 라벨을 연결합니다.

현재 제안하는 흐름은 선수 추적 → 선수 중심 크롭과 짧은 구간 분할 → VLM 동작 설명 → 키워드 기반 라벨링과 품질 선별입니다. 같은 클립에서 추출한 메쉬를 설명·라벨과 연결하려 합니다.

그라운딩과 메쉬 비교 실험은 수행했지만, 이 변경안 전체가 자동으로 검증된 데이터셋을 만드는 단계까지 완료된 것은 아닙니다. 클립 경계, 복수 동작의 라벨링, 인물 ID 일관성과 품질 선별 기준을 구체화하고 있습니다.
