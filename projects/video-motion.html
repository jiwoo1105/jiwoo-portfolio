Overview

하나의 행동, 하나의 사람,
하나의 모션 데이터.

기존 영상에서 행동이 일어나는 구간을 찾고, 대상 인물의 3D 모션과 설명을 연결하는 데이터 구축 파이프라인을 연구합니다. 로봇 학습에 활용할 수 있도록 원본 영상, 시간 구간, 인물 ID와 복원 결과를 함께 기록하는 구조를 설계했습니다.

GPU 실행 환경과 모델별 실행기, 출력 파서, 3D 복원 모델 비교 및 대상 인물 분리를 담당했습니다. 동작 구간과 인물의 일관성을 검수하는 과정에 집중하고 있습니다.

  1. 01 / FIND행동 구간 탐색

    언어로 지정한 동작의 시작과 끝을 찾습니다.

  2. 02 / TRACK대상 인물 연결

    프레임이 바뀌어도 같은 사람을 따라갑니다.

  3. 03 / RECONSTRUCT3D 모션 복원

    인체 메쉬와 시간·인물 정보를 함께 저장합니다.

Mesh demo

움직임을, 입체적인 데이터로.

공개 농구 영상 8초, 100프레임에 CoMotion을 직접 실행했습니다. 모델이 출력한 자세·체형·위치 파라미터를 SMPL 인체 메쉬로 변환하고, 원본 영상과 같은 카메라 시점으로 렌더링했습니다.

위 영상은 포트폴리오용으로 새로 만든 복원 예시입니다. 가려진 신체 부위와 빠른 동작에서는 추정 오차가 남을 수 있으며, 로봇에 동작을 학습시키거나 전이한 결과를 뜻하지는 않습니다.

공개 입력 영상 ↗CoMotion ↗

Temporal grounding

짧은 동작은 FPS만으로
해결되지 않았습니다.

별도의 스포츠 그라운딩 실험에서는 7개 모델, 5개 FPS, 2개 영상, 3개 쿼리의 210개 응답을 비교했습니다. FPS를 높이면 입력에 짧은 동작이 들어올 가능성은 커졌지만, 구간을 너무 넓게 반환하거나 없는 행동을 찾는 문제가 남았습니다.

후속으로 Qwen3-VL의 2초 구간 행동 판별을 TimeLens2 앞에 연결했습니다. 없는 슛을 제거한 사례와 실제 드리블까지 누락한 사례가 함께 나타났습니다. 오탐 감소만으로 성공을 판단하지 않고, 놓친 동작과 처리 비용을 함께 비교했습니다.

Identity & validation

사람이 바뀌면,
모션 데이터도 섞입니다.

CoMotion과 Multi-HMR 2의 인물 추적을 비교하고, 중복 검출을 줄이기 위해 박스 겹침과 중심 위치를 함께 확인했습니다. 다만 중복 제거가 인물 ID 유지까지 보장하지는 않았습니다.

전신을 유지한 인물 크롭과 재추론도 비교했습니다. PHALP + 4D-Humans는 별도의 비교군으로 실행 환경과 검증 절차를 정리했습니다. 검출, ID 일관성, 3D 복원 품질을 구분해 검토하는 것이 이 작업의 핵심입니다.

Stack & evidence

실행 결과를 다음 실험의 기준으로.

Python / PyTorch / FFmpeg / TimeLens2 / Qwen3-VL / CoMotion / Multi-HMR 2 / PHALP / 4D-Humans / Docker
