01 · 문제 정의

모델의 출력을 모으는 것만으로는 학습 데이터가 되지 않았습니다.

영상에서 행동 구간을 찾고 3D 모션과 설명을 묶으려면, 모든 결과가 같은 사람의 같은 순간을 가리켜야 합니다. 구간을 잘못 찾거나 ID가 바뀌면 그럴듯한 메쉬와 설명도 서로 다른 장면을 나타낼 수 있었습니다.

저는 ETRI 연구과제에서 파이프라인 전반의 설계·구현을 주도했습니다. 먼저 7개 모델·5개 FPS·2개 영상·3개 쿼리의 210개 응답을 비교했습니다. FPS를 높여도 행동 누락과 넓은 구간 예측이 남아, 그라운딩 출력을 곧바로 정답으로 삼지 않는 방향으로 설계를 바꿨습니다.

확인한 결과

인물 ID와 원본 시간축을 먼저 보존하고, 각 단계의 결과를 대조할 수 있는 연결 구조를 만들었습니다.

이 경험에서 얻은 기준

파이프라인의 핵심을 모델 수가 아니라 데이터 간 대응 관계로 정의했습니다. 이후 단계가 앞 단계의 오류를 숨기지 않도록 원본과 중간 결과를 함께 남겼습니다.

02 · 데이터 연결

크롭과 메쉬를 원본의 인물·프레임에 묶었습니다.

전체 화면의 ViTDet-H 검출과 HMR 2.0 추정을 PHALP가 연결해 인물 ID를 만듭니다. 저는 검수한 선수와 연속 구간을 선택하고, 박스 각 변에 10% 여백을 둔 크롭에 HMR 2.0을 다시 실행했습니다.

원본 시각·프레임 번호·ID·크롭 좌표를 SMPL 결과와 함께 저장했습니다. 각 단계의 프레임 수와 FPS도 확인해, 이상한 메쉬를 발견하면 입력 구간까지 되짚을 수 있게 했습니다. 별도 공연 검수에서는 일시 누락과 타인에게 붙은 ID를 구분해 제외·보류 기준을 정리했습니다.

확인한 결과

선택한 선수 5명의 6구간에서 크롭·SMPL 파라미터·메쉬를 연결했습니다. 영상은 저장된 메쉬의 고정 루트 재생이며, 로봇의 균형 제어 시연과 구분합니다.

03 · 행동 설명 검수

문장이 자연스러워도, 공을 가진 선수는 틀릴 수 있었습니다.

검수한 모션에 행동 설명을 붙이기 위해 같은 6개 RGB 크롭을 4 FPS로 입력하고 Qwen·InternVL의 프롬프트 세 조건을 비교했습니다. 입력 프레임과 모델 버전을 고정하고 실제 요청·응답 36개를 보존했습니다.

행동을 명시적으로 질문해도 공이 없는 선수의 드리블을 설명하거나, 드리블 후반의 공 릴리스를 놓쳤습니다. 프롬프트를 바꾼 뒤 문장이 풍부해진 것과 행동을 더 정확하게 설명한 것을 따로 판단했습니다.

확인한 결과

캡셔닝 비교는 완료했지만 자동 행동 정답의 품질은 확보하지 못했습니다. 최종 프롬프트 선택을 최고 정확도 달성으로 해석하지 않았습니다.

이 경험에서 얻은 기준

생성 성공을 데이터 품질 승인과 분리했습니다. 학습 데이터에는 “설명 있음”보다 “누구의 어떤 행동을 실제로 설명하는가”를 확인하는 절차가 필요했습니다.

04 · 로봇 적용의 경계

메쉬는 재생됐지만, 전신을 따라가던 로봇은 넘어졌습니다.

저장된 SMPL을 GMR로 G1의 29관절에 매핑한 뒤 물리 시뮬레이션에서 추종을 시험했습니다. 초기 자세·속도·발 접촉을 확인하고, 시작 시각 변경·초기 속도 제거·접촉 보정과 PPO 추가 학습을 비교했습니다.

접촉 보정 후 2,000회 학습한 전신 과제도 평가 10회 모두 실패했습니다. 원인을 좁히기 위해 하체·허리를 서 있는 목표로 바꾼 팔 중심 과제를 따로 평가했고, 같은 짧은 모션의 초기 교란 시험에서는 10회 모두 통과했습니다.

확인한 결과

관절 변환과 정책 학습·평가는 실행했습니다. 팔 중심 과제의 제한적 통과와 미해결인 전신 추종을 구분했으며, 공 상호작용과 실제 로봇 배포는 수행하지 않았습니다.

이 경험에서 얻은 기준

영상에서 복원한 동작이 로봇이 실행할 수 있는 동작은 아니었습니다. 데이터 형식·기구학 재생·물리 추종을 나눠 검증하고, 실패할 때 과제를 좁혀 원인을 분리하는 기준을 얻었습니다.

05 · 남은 과제

각 단계의 성공 기준을 나눈 파이프라인으로.

이 연구에서 만든 것은 모델 실행을 연결한 코드뿐 아니라, 원본으로 돌아가 오류를 확인하고 사용할 구간을 판단하는 구조입니다. 구현·실험·검수와 문서화에는 AI 코딩 도구를 활용했고, 사전학습 모델의 자체 개발이나 파인튜닝 성과로 소개하지 않습니다.

다음 과제는 ID·행동 설명·모션 품질을 함께 승인하는 절차와 전신 추종 안정화입니다. 현재는 선택 구간의 데이터 구축과 독립 파일럿까지 수행한 연구이며, 전체 영상에서 로봇 학습까지 자동으로 완주하는 시스템은 아닙니다.
