- 대표 4개: 로봇학습데이터 구축 파이프라인, Conquer Health, 단짠, 축구 드리블 분석
- Other projects: 넙치 증상 탐지, MedGuard, MedAI Agent의 실제 대표 화면·영상
- 7개 프로젝트의 한·영 상세 페이지: 결론을 먼저 제시하고 배경·개인 역할, 난제와 해결, 결과·검증, 배운 점으로 구성
- 실제 모델 출력 영상과 서비스 시연, 팀 수상 증빙

서비스는 별도 런타임이나 패키지 설치 없이 동작하는 정적 HTML/CSS/JavaScript입니다. 수정할 때만 Python 표준 라이브러리로 한·영 페이지를 생성합니다.

## 수정과 배포

소개·프로젝트 내용은 `content/site_content.py`의 한·영 쌍을 수정합니다. 레이아웃은 `scripts/build.py`, 공통 디자인은 `assets/site.css`, `assets/refresh.css`, `assets/portfolio.css`, 상호작용은 `assets/site.js`, 테마와 언어 전환은 `assets/preferences.js`에 있습니다. 생성된 HTML을 직접 수정하지 마세요.

```sh
python3 scripts/build.py
python3 scripts/check.py
```

생성된 16개 HTML도 함께 커밋합니다. 한국어는 루트, 영어는 `en/` 아래에 있으며 내부 탐색과 새로고침에서 언어가 유지됩니다. 언어 전환은 같은 상세 페이지·섹션으로 이동합니다. 기본 테마는 라이트이고 선택한 테마는 `localStorage`에 저장합니다. 모든 내부 경로는 상대 경로여서 GitHub Pages 저장소 하위 경로에서 동작합니다.

`main`에 push하면 `.github/workflows/pages.yml`이 GitHub Pages로 배포합니다. 저장소 Settings → Pages → Source는 **GitHub Actions**입니다.

단순 로컬 확인:

```sh
python3 -m http.server 8765
```

영상의 특정 시점 이동까지 검증하려면 HTTP Range 요청을 지원하는 서버 또는 실제 GitHub Pages를 사용하세요. Python 기본 서버에서는 일부 브라우저의 영상 탐색이 제한될 수 있습니다.

## 실제 영상으로 보는 파이프라인

`assets/motion/`은 입력, PHALP ID 추적, 인물 크롭, HMR 2.0 오버레이, MuJoCo 메쉬 재생, 크롭/메쉬 나란히 비교의 무음 MP4 6개와 포스터, 메인용 합성 쇼릴입니다. 출처·시간 대응·파일 해시는 `assets/motion/manifest.json`에 기록했습니다. 모든 단계가 6초·360프레임·60 FPS로 일치합니다.

상세 페이지의 `assets/motion-showcase.js`는 재생 위치와 속도를 유지하며 단계를 전환합니다. 재생/일시정지·탐색·전체 화면은 브라우저 기본 제어를 쓰며, 0.5/1/2배속을 선택할 수 있습니다. 방향키·Home·End로 단계 선택이 가능하고, JavaScript가 없으면 비교 영상과 단계별 파일 링크를 제공합니다. 상세 영상은 자동 재생하지 않으며 메인 미리보기는 기존 모션 정지 설정을 따릅니다.

MuJoCo 영상은 실제 저장한 SMPL 정점을 고정 루트로 재생한 **기구학적 시각화**입니다. 월드 이동 경로 복원, 충돌·균형 제어, 특정 로봇 리타게팅, 정책 학습 완료를 의미하지 않습니다. 전체 자동 행동 분할·캡셔닝·품질 승인도 후속 과제입니다. 최신 실험의 범위와 공개 팀 저장소의 초기 실행 가이드를 구분합니다.

메인 카드의 `assets/motion/cover.mp4`는 같은 360프레임의 원본·PHALP 추적·SMPL 메쉬 재생을 한 화면으로 편집한 960×720 쇼릴입니다. 인물이나 움직임을 새로 생성하지 않았습니다. 메쉬 재생본의 진단 헤더와 빈 주변부만 잘라 레이아웃에 배치하고, 고정 루트 재생이라는 설명은 한국어·영어 HTML 라벨로 표시합니다. 원래 단계별 파일은 상세 페이지에서 그대로 확인할 수 있습니다. `manifest.json`에 표시용 크롭과 파일 해시를 기록했습니다.

두 언어의 원고를 직접 제공하므로 `translate="no"`와 Google 번역 제외 메타를 설정했습니다. 브라우저의 자동 번역이 grounding·runner·PHALP 같은 전문용어를 바꾸는 일을 줄이며, 상단 KO/EN으로 대응 페이지를 이동할 수 있습니다.

헤더는 모든 페이지에서 고정되며 밝은·어두운 테마에 맞는 불투명 배경을 사용합니다. 작은 화면에서는 상단에 이름·KO/EN·테마, 하단에 프로젝트·소개·수상/자격·연락 메뉴를 배치합니다. 앵커 이동과 상세 목차의 고정 위치는 공통 헤더 높이를 기준으로 맞췄습니다. 수상·자격·교육 섹션은 루닛 AIM 팀 벤치마크상, SQLD 자격, AWS 교육 수료를 구분해 표시합니다.

2026-11-03 추가 본인 확인을 마스터에 먼저 반영한 뒤, 로봇 프로젝트의 개인 기여를 **파이프라인 전반 설계·구현 주도, 모델 연동·실험·결과 검수**로 정정했습니다. 사전학습 모델 자체의 개발을 주장하지 않습니다. 메인 카드는 처리량 대신 원본 시간·인물 ID·크롭·3D 모션의 프레임별 연결과 오류 구간 선별 기준을 설명하며, 처리량은 상세의 실험 범위에 남깁니다. IDF1/HOTA나 정답 기반 3D 정확도 수치는 측정하지 않아 추가하지 않았습니다.
